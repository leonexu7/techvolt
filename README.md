# TechVolt - Sitio Web de Servicios Eléctricos

Sitio web oficial de **TechVolt**, soluciones eléctricas seguras y profesionales para clientes residenciales y comerciales en Tehuacán y zonas cercanas.

## Tecnologías Utilizadas
- **HTML5 Semántico**: Estructura optimizada para accesibilidad y SEO.
- **CSS3 Puro**: Diseño Mobile-First, paleta técnica con acentos pastel, sin frameworks ni dependencias pesadas.
- **JavaScript Vanilla**: Lógica de cotización en tiempo real, persistencia en `localStorage`, integración con la API de WhatsApp y panel de administración interactivo.
- **Lucide Icons**: Iconografía técnica limpia mediante CDN.

## Funcionalidades Principales
1. **Cotizador Interactivo de Presupuestos**:
   - Modo A: Lista de precios con cálculo instantáneo por pieza/servicio.
   - Modo B: Diagnóstico técnico por síntomas de falla.
   - Selector de urgencia y captura de ubicación/referencia.
   - Envío directo del presupuesto formateado a WhatsApp (`+52 221 982 9074`).
2. **Fotografía Real y Portafolio**:
   - Evidencia gráfica de trabajos realizados en centros de carga y cableados.
3. **Panel Secreto de Administración**:
   - Acceso con contraseña (`2026` por defecto).
   - Edición en vivo de precios, servicios y galería de trabajos.
   - Descarga de archivo `datos.js` actualizado para sincronización permanente.
